# TaskApp API VPS Deploy

This deploys `TaskApp.Api` behind Caddy with automatic HTTPS.

## Prerequisites

- A VPS with Docker and Docker Compose.
- DNS `A`/`AAAA` record for your domain pointing to the VPS.
- Ports `80` and `443` open.

## Deploy

```bash
cp deploy/vps/.env.example deploy/vps/.env
# Edit deploy/vps/.env:
# - TASKAPP_DOMAIN
# - TASKAPP_API_KEY

docker compose --env-file deploy/vps/.env -f deploy/vps/docker-compose.yml up -d --build
```

## Verify

```bash
curl https://YOUR_DOMAIN/health

curl -i https://YOUR_DOMAIN/api/accounts
# Expected: 401 without X-TaskApp-Api-Key
```

Create an account:

```bash
curl -X POST "https://YOUR_DOMAIN/api/accounts" \
  -H "Content-Type: application/json" \
  -H "X-TaskApp-Api-Key: YOUR_API_KEY" \
  -d '{"displayName":"Desktop account"}'
```

Save both values returned by that response:

- `id`: the account ID
- `loginSecret`: the account secret used by desktop and Android clients

Verify login:

```bash
curl -X POST "https://YOUR_DOMAIN/api/accounts/login" \
  -H "Content-Type: application/json" \
  -d '{"accountId":"YOUR_ACCOUNT_ID","loginSecret":"YOUR_LOGIN_SECRET"}'
```

## Desktop Settings

Set:

- API URL: `https://YOUR_DOMAIN`
- Server API Key: the `TASKAPP_API_KEY` value from `.env`, needed to create a new account
- Account ID: generated by `Create Account`, or paste one returned by `curl`
- Account Secret: saved automatically by `Create Account`, or paste `loginSecret` from `curl`

Click `Login`, then `Upload All Profiles` to push every local desktop profile under the same cloud account. Keep the server API key private; Android only needs the account ID and account secret.
